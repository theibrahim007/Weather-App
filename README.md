# Weather App 🌤️

A clean, modern weather application built with HTML, CSS, and Vanilla JavaScript.

## Features
- Search weather by city name.
- Dynamic weather icons (Clouds, Rain, Clear, etc.).
- Real-time temperature, humidity, and wind speed using the OpenWeather API.
- Responsive design and custom CSS gradients.
- Error handling for invalid city names.

## How to Run
1. Clone the repository.
2. Add your own OpenWeather API key in the `script.js` or `<script>` tag.
3. Open `index.html` in your browser.
